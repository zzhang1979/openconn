# openconn

Native Qt Quick frontend for OpenConnect SSL VPN client.

## Highlights
- Multi-profile management with local credential persistence
- Two-phase connection flow (unprivileged auth + elevated tunnel setup)
- Interactive console input for 2FA/OTP prompts
- Automatic SSL server fingerprint retrieval
- Wayland and X11 support

## Build
```bash
./bin/build
./bin/install
```
